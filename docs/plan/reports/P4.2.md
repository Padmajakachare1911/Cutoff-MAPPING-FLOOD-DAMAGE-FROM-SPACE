# P4.2 - one-page situation report

Added StrictUndefined/autoescape Jinja template and HTML-to-PDF renderer. WeasyPrint
is preferred; unavailable native dependencies fall back to xhtml2pdf. The renderer
validates Results and verifies exactly one PDF page, trying compact typography if
needed. Every analytical statistic comes from Results. Presentation-only list
truncation uses the scenario's recorded count; maximum 15 settlement names.

Report contains disclaimer/synthetic status, observation provenance, hazard and
no-observation areas, exposure, A/B/C counts, scenario B names, trail-access caveat,
warnings, five shortest limitations, and complete attribution.
