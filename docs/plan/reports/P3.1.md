# P3.1 — OSM stage

## Built

- Strict pre-event timestamp guard; the literal `latest` and snapshots at/after the event are rejected.
- ohsome v2 GeoParquet extraction with three attempts and exponential backoff, followed by the v1 geometry fallback.
- Roads, buildings, places, and health normalization into the frozen vector contracts, including road tiers,
  bridge flags, health kinds, polygon centroids, OSM IDs, and tag flattening.
- 0.1-degree request tiling, OSM-ID deduplication, a 15 km access extent for roads/places/health, grid-CRS
  GeoPackages, and per-grid parquet caching.
- Cached-mode and failed-request cache fallback with run warnings.
