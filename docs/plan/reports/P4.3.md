# P4.3 - dashboard

Added Streamlit product with AOI/date/mode/model inputs, pre-event OSM override,
non-blocking CLI subprocess launch, automatic JSON-log progress refresh, run history,
and A/B/C scenario switching. Errors preserve the same-track message; partial runs
are highlighted. All analytical statistics come from Results. Maps use contract
rasters and pre-event GeoPackages, with no contemporary basemap data.

Display layers: Mercator-warped hazard tiers, hatched no-observation, calibrated
global-flood model score, pre/post VV dB, optional S2 water evidence, exposed
buildings/roads, scenario closures/settlements, and optional flow path. Settlement
popups show status/travel time/trail access. Clicking hazard cells explains flags.
Downloads include PDF, hazard/settlement GeoPackages, GeoTIFF and JSON. Attribution
appears in the footer; OSM web exports carry ODbL notice. Evaluation tab appears
only when the run_id is listed in frozen_runs.txt.
