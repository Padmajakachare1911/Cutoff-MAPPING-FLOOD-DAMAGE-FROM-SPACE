# Task reports

One file per task: `<task-id>.md` (e.g. `P1.3.md`). Each report covers:

- what was built;
- the exact test commands and the tail of their output;
- deviations from the plan, and why;
- open issues.

Checkpoint reports: `C1.md`, `C2.md`, `FREEZE.md`. Organiser answers: `organiser_answers.md`.
