# P1.3 — Sentinel Hub backend (fast mode)

## What was built
`src/cutoff/data/sentinelhub.py`:
- `get_token(client_id, client_secret, token_url)`: client-credentials token, cached per (client, url) until
  60 s before expiry.
- `sh_credentials()`: reads `SH_CLIENT_ID` / `SH_CLIENT_SECRET` from the environment or the git-ignored `.env`.
  Raises `MissingCredentials` with a clear message.
- `chunk_windows(grid, 2500)` / `chunk_grid(grid, win)`: grid-aligned ≤ 2500 px chunks that tile the grid exactly once.
- `s1_request_body(scene, chunk, cfg)`: the plan's request body.
  - bbox = chunk bounds in grid-CRS metres; CRS `http://www.opengis.net/def/crs/EPSG/0/<grid epsg>`.
  - `timeRange` = scene.start − 60 s → scene.end + 60 s; `orbitDirection` = the scene's direction.
  - IW / DV / HIGH; `SIGMA0_ELLIPSOID`, `orthorectify`, `COPERNICUS_30`, speckle `NONE`.
  - The evalscript returns VV, VH, localIncidenceAngle, dataMask as FLOAT32. Processing values come from
    `configs/default.yaml`.
- `fetch_s1_scene(scene, grid, cfg) -> (4, H, W) float32`.
  - Each chunk's TIFF is read, its transform is checked against the chunk grid (raises if it differs), and it is
    placed into its window.
  - 429/5xx responses are retried.
  - Each request calls `log(event="sentinelhub_request", processing_units=<x-processingunits-spent>, ...)`.
    `stage_s1` passes `ctx.log`, so processing units go into `run.log`.
- `s2_request_body` / S2 evalscripts, used by P1.6.

## Tests

```
python -m pytest tests/test_p1_sentinelhub.py -q -p no:warnings -rs
......s
SKIPPED [1] tests\test_p1_sentinelhub.py:145: Sentinel Hub credentials missing: set SH_CLIENT_ID and SH_CLIENT_SECRET in .env ...
```
- Mocked HTTP:
  - chunk TIFFs encoding their global row/col land in the right windows of the full array (6 chunks);
  - the tiling covers a 6001 × 2600 grid exactly once;
  - the request carries the ±60 s window and `ASCENDING`;
  - an off-grid response is rejected;
  - the token is cached until expiry;
  - missing credentials give a clear error;
  - processing units are logged per request.
- `@pytest.mark.network` live test: Trishuli post scene 85A 08-28, a 5 × 5 km chunk. It checks that the response
  transform equals the chunk grid, the VV median is in [0.01, 0.3], and LIA is in [0, 90] on > 90 % of pixels.
  **Not run: skipped, no credentials on this machine** (see P1.0).
