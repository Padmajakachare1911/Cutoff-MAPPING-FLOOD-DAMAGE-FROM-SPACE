# E6 — Cut-off robustness

## Correctness evidence

The synthetic graph tests in `tests/test_p3_network.py` cover intersection noding and bounded closure, all four
statuses, bridge approach logic, grade-separated crossings, parallel edges, long-detour degradation, and random
edge dropout. The P3.4 task run passed all five tests.

## Frozen Trishuli results

Pending a frozen real Trishuli run. Run the reproducible evaluation with:

```text
python eval/access_eval.py outputs/<frozen-trishuli-run> --out docs/results/raw/E6.json
```

The output contains, for scenarios A/B/C, closed road kilometres, closed bridge counts, each access-status count,
cut-off-set Jaccard against A, and 20-run 10%/20% edge-dropout stability per settlement. No numerical results are
reported here until measured.
