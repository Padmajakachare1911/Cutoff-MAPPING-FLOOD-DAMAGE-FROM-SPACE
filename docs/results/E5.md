# E5 — Same-track vs cross-track change detection

**Status: RUN on 2026-10-13** (fast mode, Sentinel Hub + `lee_sigma`, model `model-v1` = `cutoff_unet_v1.pt`, thresholds
frozen; nothing tuned on Trishuli). Raw returns: `docs/results/raw/E5_{same,cross}_stage_returns.json` (copies of `outputs/e5_*/stage_returns.json`).

## Hypothesis (pre-registered)
**H3:** a cross-track pre/post pair gives a higher false-positive rate on stable steep terrain than the same-track
pair: `stable_steep_fpr(cross) > stable_steep_fpr(same)`. The reason is that the viewing geometry changes between
ascending and descending passes, so terrain-induced backscatter changes appear as "change" on steep slopes.

## Results
| Run | Pre scenes | stable_steep_fpr | Flood area km² (class 1 + 2) | σ stable (disturbance, dB) | Rule decrease / increase km² | Permanent water km² | No observation km² |
|---|---|---|---|---|---|---|---|
| same-track | 85A 08-16, 08-04, 07-23 | **2.1 × 10⁻⁶** | **0.005** (high 0.000, possible 0.005) | 1.31 | 0.164 / 0.076 | 9.77 | 1.59 |
| cross-track | 19D 08-24, 08-12, 07-31 | **0.295** | **87.27** (high 0.95, possible 86.32) | 14.71 | 0.000 / 0.000 | 39.12 | 1.59 |

Both runs: same post scene (85A 2026-08-28), grid 1404 × 2125 px, 2,546,000 stable pixels (HAND > 100 m).
The cross-track run warned "Sentinel-1: CROSS-TRACK pre/post pair (experiment E5 only)".

**H3 holds, by a wide margin.** The cross-track pair raises the false-positive rate on stable steep terrain from
2 × 10⁻⁶ to 0.30. About 30 % of stable steep pixels become "flood", which inflates the flood area from 0.005 km² to
87 km². The scene-wide stable-terrain σ used by the disturbance rule grows from 1.3 dB to 14.7 dB, because the
ascending vs descending geometry flips which slopes face the radar. That 3σ threshold then rejects every real change:
rule decrease/increase drop to 0. This is the evidence behind the "same track only" rule in `select_pairs`.

### Observations for P2 (no tuning; reported, not acted on)
- **Same-track Trishuli: the model alone finds almost no flood** (0.005 km² in classes 1–2); the hazard comes from the
  change rule (0.16 km² decrease + 0.08 km² increase). This is consistent with D6/E2 (Himalayan slopes are out of
  distribution) and is what the rule layer is for.
- **"Permanent water" 9.77 km² (same-track) is mostly radar back-slopes, not water.** Of those pixels, 94 % have
  HAND > 30 m (median 380 m), 98 % slope > 15° (median 43°), 73 % LIA > 70° (median 77°, near shadow); VV median
  −19 dB. Gating rule 4 (`p_permanent ≥ τ` → class 5) has no terrain check, unlike rule 3 for flood. Flood/exposure
  numbers are unaffected, but the dashboard would show water on mountainsides. Contract/P2 decision.
