# E4 - check-only evaluation status

European Union, Copernicus Emergency Management Service data.

**Harness implemented and tested; real comparison deferred until corrected-data
integration and project freeze. No real E4 scores have been computed.**

Prepared references: latest delivered grading/monitoring packages for AOIs 1, 2,
3 and 5; schema/date/legend inventory in `docs/plan/reports/P4.0_reference_schema.md`.
The observed-event layer is mass movement, so definition mismatch with SAR water
must be interpreted explicitly. Built-up reference layers contain points rather
than footprints; footprint recall is unavailable when no polygon layer exists.

The harness clips to shared AOI coverage, removes not-analysed reference regions,
excludes no-observation pixels from P/R/F1/IoU, reports their share of the reference,
computes boundary F1 at 30 m, and exports 5 km agreement tiles. Primary mask is
classes 1/3/4; secondary includes class 2. Empty denominators are n/a, never zero.

After full integration, freeze a clean exact `frozen-v1` checkout and run once:

```text
python eval/emsr927.py --run outputs/trishuli_north_frozen --reference reference/EMSR927 --report docs/results/E4.md
```

The script refuses dirty/unfrozen code, synthetic runs and repeat attempts. It
records hashes and leaves the human taxonomy pending: cloud/timing, radar geometry,
DEM/gorge, definition mismatch and OSM. No retuning after this comparison.
